# Corevolvix marketing site

This is a self-contained, responsive marketing site for Corevolvix. It uses the supplied Corevolvix wordmark and includes a custom SVG favicon.

## Preview locally

From `D:\CorEvolvix`, run:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080` in a browser.

## Included assets

- `assets/corevolvix-wordmark-transparent.png` — cropped, transparent version of the supplied company logo used by the site
- `assets/corevolvix-logo.jpeg` and `assets/corevolvix-mark.png` — original provided image assets
- `assets/favicon.svg` — lightweight vector favicon based on the Corevolvix mark
